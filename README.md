# CineMorph AI

CineMorph is a browser-first AI video creation workspace.

## Features
- Studio dashboard
- Scene-plan generator from a written concept
- Script Writer
- Visual timeline
- Local media library for images, video and audio
- Local project persistence with `localStorage`
- JSON project export
- Responsive desktop/mobile UI

## Run

No build step or npm install is required. Open `index.html` in a modern browser.

## GitHub Pages

This is a static site and can be deployed from the `main` branch root using GitHub Pages.

## Note

The app works without external API keys. Its planning and script generation are browser-side deterministic features. A real AI/video-generation provider can be connected later through a secure backend; API keys should never be committed to this repository.
